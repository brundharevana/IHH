# Rooms index

A plain-language map of where each part of the tour comes from. The research files are in this repository (`data/inductees/<slug>/`); the room folders (`assets-src/<room>/`) are in the app repository (branch revamp/mockups), linked here by their path from the repository root. Those links resolve only in the app repository on branch revamp/mockups (where data/ and assets-src/ sit side by side); in this repository assets-src/ is not present. Machine-readable: `site-provenance.jsonld`.

36 chapters: 22 recreated rooms, 7 photo rooms, 7 gallery cases. 4 labelled object recreations. 214 spoken lines tied to facts or room inventories, 346 wayfinding lines, 122 records a visitor can open.
