## Method

1. Read the skill, SPEC, PATTERNS and LESSONS; inventoried the 115 saved snapshots for each
   place name before searching (search log ALB-Q entries of run albright-tour-2026-10-15).
2. Searched in batches by stop: WebSearch (ship name, London, Belgrade, Truman Building,
   Wellesley, Kent School), the Office of the Historian buildings pages (WebFetch), the NARA
   catalog proxy API (5 queries), and the loc.gov JSON API (photos, books, telephone
   directories). Wikipedia, Wikidata and aggregators were used only to find leads.
3. 1997-2001.state.gov returns an error page to non-browser clients, so candidate transcript
   URLs were probed and read in the Browser pane; three pages (ALB-S-0116 to -0118) were saved
   with `fetch_snapshot.py --from-file --method browser` from the pane's page text. LoC items were
   saved by `fetch_snapshot.py` (JSON, method api); bushcenter.org by http.
4. Claims were written in the quotes' own words, one event each; 20 facts and 5 media were
   staged in `staging/tour.jsonl` with 35 searches, merged with `merge_staging.py` (the LoC
   rights rule set the five media to public-domain from the holder advisories), then
   `compute_status.py` and `validate.py` (0 errors).
5. Adversary: `adversary.py --engine codex --model gpt-6.1-sol` (codex-cli 0.162.1) on the 25
   new items and 6 tour-relevant disputed facts, 21 batches, run adv-albright-tour-2026-10-15:
   26 supported, 5 refuted (the five place photographs), 0 unclear. Codex reached the
   1997-2001.state.gov transcripts through web search and marked them found.
6. `compute_status.py`, then `validate.py albright`: OK, 0 errors, 67 warnings (pre-existing
   kinds: REFS, ALIASES, G5 corroboration notes, G10 browser-snapshot notes, G6 draft re-judging
   notes).
